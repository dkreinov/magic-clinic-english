# english-app

A personal English-learning PWA for one Hebrew-speaking 11-year-old. A
placement test calibrates which English words she knows, then a serialized
story about a girl apprenticed to a veterinarian for magical creatures is
generated, constrained to ~95–98% words she already knows, with
tap-to-translate and inline comprehension checks.
